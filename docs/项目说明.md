# ASRA
AI Styling Recommendation Assistant
AI智能穿搭推荐助手

## 项目介绍
ASRA是一款基于人工智能技术的智能穿搭推荐系统。
系统通过用户衣物数据、图片识别技术以及推荐算法，帮助用户完成衣物管理和个性化穿搭推荐。

## 技术栈

### Backend

- Python
- FastAPI
- SQLAlchemy


### AI
- Computer Vision
- LangChain
- LangGraph

### Database
- SQLite (开发阶段)
- PostgreSQL / SQL Server (生产阶段)

## 核心功能
- 用户账户管理
- 衣物数字化管理
- AI衣物图片识别
- 智能穿搭推荐
- AI Agent穿搭助手

## 项目目标
通过人工智能技术，
帮助用户
1. 管理个人衣柜
2. 快速生成穿搭方案
3. 提升日常穿衣效率
